# Rotem Gatenyo - Personal Website

Static personal and academic portfolio hosted with GitHub Pages.

## Pages

- `index.html` - introduction, background, research interests, and selected work
- `publications.html` - papers and research outputs
- `projects.html` - research, engineering, and creative projects

## Before publishing

Replace the placeholder links and text:

1. Scholar, email, and LinkedIn links in `index.html`
2. Publication authors, descriptions, and resource links
3. Project descriptions, images, videos, and links
4. Placeholder files in `assets/images`, `assets/pdfs`, and `assets/videos`

## Local preview

Open `index.html` directly, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
